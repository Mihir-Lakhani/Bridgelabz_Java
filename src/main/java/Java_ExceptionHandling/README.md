# Exception Handling Practice Assignments

Run these examples from the project root. Each numbered item matches the assignment checklist.

1. Read a file and handle a missing file: `IOExceptionPractice.java`
2. Divide two user inputs and handle invalid input or division by zero: `DivideUserInput.java`
3. Read multiple files using `processFiles(List<String>)`: `IOExceptionListOfFiles.java`
4. Rethrow a division error with context: `DivisionRethrow.java`
5. Register users and handle duplicate or missing users: `Main.java`
6. Combine two files into a third file: `CombineFiles.java`
7. Rethrow a transaction error with transaction details: `TransactionContext.java`
8. Handle checked and unchecked exceptions: `CheckedUncheckedExceptions.java`
9. Show automatic resource cleanup after a failure: `ResourceCleanup.java`
10. Close database and transaction resources after a failure: `DatabaseTransactionResources.java`
11. Wrap an exception and inspect its original cause: `WrapUnwrapException.java`
12. Use nested catches for parsing and file errors: `NestedTryFileParsing.java`
13. Propagate a checked calculation exception: `CalculationExceptionPropagation.java`
14. Wrap different transaction failures with transaction details: `TransactionExceptionTypes.java`

`Exception1.java` is a short `try-catch-finally` example. The text files are sample inputs for the file-reading examples.
